PROJECT CONFIGURATOR / 需求諮詢

先選需求，
再看預算。

像選 Mac 規格一樣，先選網站用途、頁面規模、視覺深度，再把需要的功能一項項加進來。每個選擇都列出價格，不先丟一個看不懂的總價。

需求諮詢起始費NT$3,000起

這是公開的初步估算器，不是正式合約或最終報價；第三方服務費與實際執行範圍會在諮詢時確認。

STEP 01 / PROJECT GOAL

你要先解決哪一件事？

先選網站的主要任務。這個選擇會決定基本工作量，後面的頁面、視覺與功能再往上加。

STEP 02 / SITE SCALE

需要多少內容？

頁面數量先抓一個範圍，之後可以再用網站地圖確認；這裡不是用頁數綁死你，而是讓預算有可解釋的起點。

STEP 03 / DESIGN DEPTH

你要多深的視覺設計？

同樣的頁面數量，視覺從快速整理到完整客製，工時與成果會不同。這裡把差異先攤開。

STEP 04 / ADD FEATURES

需要哪些功能？

勾選就加價，取消就扣回。第三方平台的月費、交易手續費與外部授權費，不會被藏在這張估算裡。

STEP 05 / FINAL ESTIMATE

最後加上你需要的協助。

這些是可以獨立選擇的加值項目。沒有選的，就不會被算進去。
